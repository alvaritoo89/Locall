# ADR 0024 · La web: páginas estáticas generadas en Rust desde el catálogo firmado

- **Estado:** aceptada
- **Fecha:** 2026-11-10

## Decisión

- La web vive en **GitHub Pages**, en `https://alvaritoo89.github.io/Locall/` (gratis con el repositorio público; sin
  dominio propio por ahora, se puede añadir después sin rehacer nada).
- Se **genera con un programa propio en Rust** (`crates/locall-web`) a partir de `catalogo/catalogo.json`:
  - la web y la app dicen siempre lo mismo (la misma fuente);
  - **se niega a generar nada si el catálogo no tiene la firma oficial buena**: nunca se publica un catálogo sin
    firmar;
  - sin dependencias nuevas (solo `locall-catalogo`): el HTML se escribe a mano y **todo texto del catálogo se
    escapa**, aunque vaya firmado (hay una prueba con un texto malicioso);
  - solo vacía su carpeta de salida si está vacía o la creó él mismo (lleva una marca): una ruta equivocada nunca
    borra nada.
- Se descartaron Astro, Hugo o Jekyll: añadirían una cadena de herramientas y decenas o cientos de dependencias para
  unas pocas páginas.
- Páginas: inicio, descargar («Próximamente» hasta el instalador firmado de la Fase 8), modelos (con filtros por uso y
  tamaño), una por modelo (con su comando `locall pull` para copiar, sus datos y su sha256), privacidad y 404. Todo
  dice «compatible», nunca «probado» (ADR 0022). Ni el ordenador del autor ni velocidades.
- **Sin nada externo:** sin cookies, sin estadísticas, sin fuentes de Google (Inter y JetBrains Mono van en la web, con
  su licencia OFL). Solo enlaces a GitHub y Hugging Face. La página de privacidad dice que GitHub registra la IP de
  quien visita (según su documentación).
- **Buscador en la página de modelos** (con JavaScript): al escribir, filtra el catálogo **sin enviar nada**; el botón
  «Buscar en Hugging Face» busca entre todos los modelos GGUF de Hugging Face **desde el navegador de quien visita**
  (Hugging Face lo permite: su API autoriza el origen `alvaritoo89.github.io`, comprobado el 2026-11-10). Solo
  entonces se envía el texto, y la página lo dice junto al botón y en la de privacidad. La petición va sin cookies ni
  `Referer`, y los resultados se pintan con `textContent` (nunca como HTML). Cada resultado lleva su
  `locall pull propietario/nombre` y el aviso de que no está en el catálogo.
- **Funciona sin JavaScript.** El script (`web/estaticos/web.js`, sin dependencias) solo añade los botones «Copiar» y
  los filtros.
- La web lleva también una copia del catálogo y su firma (`catalogo/`). La app sigue descargándolo de
  raw.githubusercontent.com (ADR 0023).

## Publicación (`.github/workflows/web.yml`)

- Al subir cambios del catálogo, la web o el generador: pruebas → generar → publicar.
- Cada acción de GitHub está **fijada a un commit** (checkout v7.0.1, upload-pages-artifact v5.0.0, deploy-pages
  v5.0.1), el trabajo que compila solo puede leer el repositorio y el que publica es el único con permiso para Pages.
- Rust 1.99.1, la misma versión que en desarrollo.
- Requisito (una vez, lo hace el autor): Settings → Pages → Source: **GitHub Actions**.

## Consecuencias

- Coste 0 €. Límites de GitHub Pages: 1 GB de web y 100 GB al mes de tráfico (orientativos), sin uso comercial.
- Para cambiar el texto de la web hay que tocar `crates/locall-web/src/lib.rs`; para los modelos, el catálogo (y
  volver a firmarlo).
